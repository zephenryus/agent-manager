## Notes

Opens each alert in one window and the customer profile in another. Keeps a spreadsheet of "customers I've already cleared this month" so they don't repeat the same checks.

> "Half my morning is figuring out what the alert is actually about. The rule name is a code. I have to look it up."

Watched P1 clear three alerts in a row as false positives. Each took roughly 4 minutes, mostly copying the same justification text between fields.

> "I've written 'activity consistent with expected business profile' so many times I have it on a sticky note."

Does not trust the risk score for ordering, but is unsure whether ignoring it is allowed. Asked us whether other teams sort differently.

> "If I get one wrong, it's my name on it. So I'd rather spend extra time than miss something."

Wishes there was a way to see "what changed" since the last time the customer alerted.
